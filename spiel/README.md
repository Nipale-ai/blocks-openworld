Open `index.html` directly, or serve this folder over HTTP.
Both work: every asset ships as a plain file and as a base64 sidecar,
because browsers block `fetch` on `file://`.

Controls: WASD move · Shift sprint · Space jump · mouse look · LMB fire ·
RMB aim · Tab (hold) weapon wheel · 1/2/3 select · R reload · E enter/exit car ·
in a car: R radio · Q horn · Space handbrake · H help · M mute · Esc release mouse
